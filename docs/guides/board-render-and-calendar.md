# Guide: board, render, and calendar

## Board

Open **Board** after a package. The board is one storyboard bound to the script throughline.

- Talent / continuity names who is on camera. Supplied notes that are not observed are labeled inferred.
- The storyboard strip has one panel per section.
- Camera filters are `all`, `a-cam`, `b-roll`, `screen`, and `insert`.
- Shot durations are hints from teleprompter pace or the model. Both are inferred.

There is no upload action. The page says generated pictures and clones are inferred.

## Render

Open **Render** and pick one mode:

| Mode | What you get |
| --- | --- |
| Shoot myself | A filmable pack. You record it. |
| Slides + voice | A watch file from the assemble timeline plus a consented voice. |
| Cinematic Shorts | A quoted short. Confirm before it runs. Default cap is 5 shots. |
| Assemble preview | Title card, thumbnail motion, captions, and chapter cards. No new API key. |

Voice consent applies only to your own voice. Cutroom does not clone people from the research grid. The review player labels a generated file inferred.

## Calendar

Open **Calendar**. Enter a theme and a planned date, then **Add to calendar**. The backlog stays on this computer. There is no Google Calendar sync.
