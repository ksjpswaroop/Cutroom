# Hermes companion experiment

Optional. **Off by default.** This is not product truth.

Cutroom can write a Monday 09:00 cron-shaped digest from a topic, a snapshot id, and observed signals you already have. The digest tells you to re-run Research before treating it as evidence.

The production sidecar does not spawn Hermes. `hermesProcessSpec()` is always `null`. Turning the Settings switch on only allows the local digest. It does not start a Python agent, a cron daemon, or a messaging gateway.

Settings → Library → **Hermes companion digest**.
